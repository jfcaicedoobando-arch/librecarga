- Tarifas multimodo: `costeo_tarifas.modo` con CHECK `costeo_tarifas_campos_por_modo` (Marítimo exige naviera/ruta/contenedor; Aéreo aeropuertos IATA; Terrestre submodalidad + CP/ciudad); tramos de peso en `costeo_tarifa_tramos`, cálculo puro en `domain/tarifaPorPeso.ts`. Why: tarifas aéreas/terrestres sin tocar las marítimas.
- Aéreo: `escalonMasBarato` aplica "as higher weight" sólo al flete (recargos por kg usan el peso tasable real); escalas IATA en `costeo_tarifas.escalas` (NULL = directo); carga mixta se guarda en `dimensiones` como líneas "N bulto(s) de L×A×H cm" separadas por "; ". Why: precio IATA correcto sin columnas extra en la solicitud.
- Charge catalog: single source in `domain/catalogoCargos` (codes GRUPO-CONCEPTO, data from `docs/catalogo-cargos-pricing.md`); surcharges store the text "CODE · Concepto" and `codigoDeConcepto` reads the code back; pre-catalog texts are kept as-is and base freights (FRT-OF/AF/LH/RL) are not offered as surcharges. Why: one code per concept without a schema change or rewriting history.
- Surcharge minimum and provider: `costeo_tarifa_recargos.minimo/proveedor` (optional); the quotation keeps the linked row at unit amount and adds an unlinked "Ajuste a mínimo" auto row for the difference; empty provider falls back to the tariff provider. Why: SQL revalidation compares each linked row to the unit amount.
